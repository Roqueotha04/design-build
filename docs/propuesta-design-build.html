01

Propuesta

Desarrollar el sitio de Design & Build a partir del documento de arquitectura web de septiembre de 2026.

El recorrido queda en cuatro páginas: inicio, proyectos, quiénes somos y contacto. Cada proyecto tiene su ficha. El sitio se entrega en español e inglés, preparado para teléfono y escritorio.

Queda incluida la base técnica del documento: formulario de contacto, SEO de arranque y la conexión con Google Analytics 4, Tag Manager, Search Console, HubSpot, Meta y LinkedIn. También un panel para cargar y quitar proyectos y servicios, y para actualizar los datos de contacto.
